## 1. Community Contributions

### 1.1 PR #25 — Full Pointer/Mouse Sequence in `firefox_click` (fixes #9)

- **Author:** `@braklo` (Branislav Klocok)
- **Problem:** `firefox_click` dispatched only a `click` event (or a reduced pair), so div-based and Blazor-style controls that listen for pointer/mouse events never responded — the issue #9 repro class.
- **Resolution:** New `extension/pointer-click.js` dispatches the real 11-event sequence at the element centre:
  `pointerover → pointerenter → mouseover → mouseenter → pointermove → mousemove → pointerdown → mousedown → focus → pointerup → mouseup → click`,
  with stable-rect scroll polling and `obscuredBy` overlay reporting. Results report `trusted: false` (synthetic events are never trusted).
- **Verification:** Regression suite `tests/pointer-click.test.mjs` (`dispatchPointerClick`, `waitForStableRect`).

### 1.2 PR #23 — MCP Requests Settle When the Host Closes the Socket

- **Author:** `@andrei-rizoiu` (Andrei Rizoiu)
- **Problem:** An unanswered host close left the MCP request hanging forever; long commands were also killed at the fixed 60 s idle socket timeout.
- **Resolution:** New `mcp/socket-request.js` replaces the inline socket state machine in `mcp/server.js`; an unanswered host close now rejects with `HOST_CLOSED`. The host raises its idle socket timeout to `commandTimeoutMs + 5s`.
- **Verification:** Regression suites `tests/mcp-socket-request.test.mjs`, `tests/ipc.test.mjs`.

### 1.3 PR #22 and PR #21 — Merged to GitHub

- **PR #22** (`@axiomvx-source`, evaluate settings race) and **PR #21** (`@braklo`, `CLAUDEZILLA_AGENT_TIMEOUT_MS` override): code shipped in AMO 0.7.0; their pull requests are merged to GitHub with this release.
